# 本轮同步内容（2026-10-21）

本轮为 AMI、Mem0、InvMem、ReFind 四方法评测补齐以下公共能力：

- **统一并发**：新增固定脚本 `scripts/run_five_seed_experiments.py`，默认调度四方法 × 五个 seed，可用 `--method` 选择单个或多个方法；支持总并发、每方法并发、断点续跑及活动队列接管，各队列独立保存输出和记忆库。
- **记忆写入分段与长文本处理**：四种方法按统一规则分批写入对话，保留原始顺序、说话者角色和时间。检索得到的长文本会分段读取并汇总，为最终回答预留输出空间；摘要因输出长度限制被截断时，继续拆分处理，并保存可复用的分段摘要。
- **评分及请求诊断**：加强 CLBench 逐项评分格式校验与有限恢复，保留首个有效评分；补充请求状态、错误码和脱敏诊断记录。
- **四方法接入整理**：四种方法的接入代码统一归入 `src/memory_benchmark/methods/`，通过同一入口加载；连接 InvMem/ReFind 原方法代码的程序从 `integrations/` 迁至 `src/memory_benchmark/runtime/native_bridge/`，继续使用各自原有的记忆存储与检索。
- **公开数据选题与运行配置**：从六个公开数据集文件中按规则选题，保存选中的题目、对应完整历史和评测参数，供四种方法共用。新增可调整的题量规则、重复生成同一题单、检查数据文件是否变化和生成本机运行配置的功能。原有五轮实验继续按已发布的题号清单重建。

## 方法选择与并发参数

| 参数 | 含义 |
|---|---|
| `--method` | 选择运行方法：`activememoryindex`（AMI）、`mem0`、`invmem`、`refind`。省略时运行四方法；可重复指定，如 `--method mem0 --method invmem`。 |
| `--parallel` | 同时运行的队列总数上限，默认 8。一个队列对应一个“方法 × seed”。 |
| `--parallel-per-method` | 同一方法同时运行的队列上限，默认 2。每个方法共有 seed 17–21 五个队列。 |

单方法五并发需同时指定方法，并把两个上限都设为 5。以 InvMem 为例：

```bash
.venv/bin/python scripts/run_five_seed_experiments.py \
  --prepared runs/prepared-five-seeds-new \
  --config configs/local \
  --output runs/invmem-five-seeds-new \
  --method invmem \
  --parallel 5 --parallel-per-method 5
```

输出及汇总只包含所选方法，各 seed 使用独立记忆库。四方法总并发 5 使用 `--parallel 5 --parallel-per-method 2`；四方法的 20 个队列同时启动使用 `--parallel 20 --parallel-per-method 5`。队列并发数与实时模型 API 请求数不同。

续跑时保持相同的方法选择、输入、输出及运行参数，追加 `--resume`；更换方法时使用新的输出目录。完整配置及运行步骤见 [运行说明](../README.md) 和 [交接文档](model_handoff_99.md)。

## 选题与配置的具体含义

| 原用语 | 具体含义与例子 |
|---|---|
| 公开来源抽样 | 读取已准备好的六个公开数据集文件，先选对话历史，再从相关题目中选题。例如从 LongMemEval-S 选一份对话历史及其关联问答，保留题目与原历史的对应关系。入口为 `scripts/sample_small_benchmark.py`。 |
| 抽样结果冻结入口 | 将选中的题号、对应完整历史、评分依据（如标准答案或评分规则）和评测参数整理成固定输入，并记录文件校验码，供四种方法读取同一份数据。入口为 `scripts/prepare_sampled_seeds.py`。 |
| v1 配额配置 | 用配置文件规定抽样数量。当前规则为每轮最多 30 份历史、每个可用能力小类至少 2 题、每个能力大类最多 40 题、每轮至少 91 题；实际题数由规则和可选题目共同决定。规则位于 `configs/small_benchmark_v1.json`。 |
| 按 seed 重放 | seed 是控制选题顺序的随机种子，例如 17。在数据版本、抽样规则和代码一致时，用同一个 seed 重新选题会得到同一份题单；当前五轮使用 17–21。 |
| 来源指纹核对 | 为来源文件计算 SHA-256 校验码并保存，准备评测输入时再次计算、逐一比较。若某个数据文件被修改，校验码变化就会触发报错，避免混用不同版本。 |
| 本机配置生成 | 根据本机目录生成源码位置、Python 环境、数据位置和凭据文件位置等配置。例如把 `baselines/InvMem` 转换为本机完整路径，便于换机器后调整运行环境。入口为 `scripts/configure_release.py`。 |

已有五轮实验直接读取 `configs/reproduction/` 保存的题号清单，按指定题目重新准备数据；需要重新选题时，再使用上述公开数据选题流程。
