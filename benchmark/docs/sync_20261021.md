# 本轮同步内容（2026-10-21）

本轮为 AMI、Mem0、InvMem、ReFind 四方法评测补齐以下公共能力：

- **统一并发**：新增固定脚本 `scripts/run_five_seed_experiments.py`，统一调度四方法 × 五个 seed；支持总并发、每方法并发、断点续跑及活动队列接管，各队列独立保存输出和记忆库。
- **Add 分段与长上下文恢复**：公共 worker 和原生桥接统一执行 Add 分段策略，保留来源顺序、角色和时间；Reader 支持长输入分段、回答空间预留、摘要截断恢复与片段缓存。
- **评分及请求诊断**：加强 CLBench 逐项评分格式校验与有限恢复，保留首个有效评分；补充请求状态、错误码和脱敏诊断记录。
- **四方法入口与原生桥接**：适配器统一归入 `src/memory_benchmark/methods/` 并注册到公共工厂；InvMem/ReFind 桥接从 `integrations/` 迁至 `src/memory_benchmark/runtime/native_bridge/`，保留原生存储与检索。
- **公开来源抽样与配置**：新增公开来源抽样、抽样结果冻结入口及 v1 配额配置；支持按 seed 重放、来源指纹核对和本机配置生成。原有固定五轮清单继续用于精确重建。

并发参数示例：总并发 5 使用 `--parallel 5 --parallel-per-method 2`；20 个队列同时启动使用 `--parallel 20 --parallel-per-method 5`。完整配置及运行步骤见 [运行说明](../README.md) 和 [交接文档](model_handoff_99.md)。
